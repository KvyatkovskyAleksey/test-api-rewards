# test-api-rewards
Тестовое задание

# Запуск
Не добавлял конфигурационный файл, так что просто
```bash
docker-compose up --build
```
Создастся суперюзер admin@admin.com с паролем 12345.
Миграции также запустятся автоматически.

# Тестирование
В корневой папке можно запустить тесты.
`./m tests`
Чтобы тестировать ручную можно получить токен на `http://localhost:8000/api/token/`
и использовать swagger `http://localhost:8000/swagger/` через 
`Authorize`.
